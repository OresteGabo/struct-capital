# Product and Website Roadmap

**Planning principle:** This is a staged hypothesis, not a delivery commitment. Implement only explicitly approved work; do not equate “documented” with “authorized.”

## Now — website foundation
- Inspect the actual Nuxt repository and existing design.
- Implement accessible responsive Home, Features, How It Works, FAQ, About, Contact, and institution-interest pages as approved.
- Explain independent cross-broker portfolio management and supported PDF workflows accurately.
- Add SEO metadata, sitemap, performance basics, and approved screenshots/assets.
- Add only verified app-store links and capabilities.
- Prefer static content; no dependency on live stats to launch.

**Exit criteria:** site builds, passes relevant checks, has accurate claims, no broken CTAs, and owner-approved content.

## Next — educational growth and feedback
- Publish reviewed articles about bonds, shares, coupons, fees, and recordkeeping.
- Improve FAQ based on real questions.
- Establish privacy-conscious feedback and measurement.
- Add a supported-document catalog when formats are verified.
- Add optional public aggregate stats only after backend and privacy review.

**Exit criteria:** useful content, discoverability, measurable feedback, and no invented product claims.

## Later — validated product and commercial growth
- Improve mobile product based on retention, import accuracy, and user needs (in KMP/backend repos).
- Test premium features only with demonstrated demand.
- Interview brokers; document workflows and pain points.
- Explore paid institutional pilots for document processing/reconciliation/reporting.
- Evaluate consent-based broker integrations only with formal agreements.

## Optional long-term strategic paths
- Recurring B2B software contracts and institution APIs.
- Expanded financial education/data products with verified rights.
- Separately authorized brokerage only after financial, operational, and regulatory evaluation.

## Deferred explicitly
Trading, custody, full broker CRM, enterprise multi-tenancy, paid subscription checkout, automated broker account access, personalized regulated advice, and speculative live market feeds.

## Decision gates and metrics
| Gate | Evidence required |
|---|---|
| Public launch | Accuracy, reliability, privacy review, release readiness |
| Marketing spend | Retention and measurable acquisition learning |
| Monetization | Willingness to pay and support economics |
| Institutional pilot | Interview evidence, scoped paid problem, security readiness |
| Direct broker sync | Agreements, consent, legal/security review |
| Brokerage consideration | Licensing feasibility, capital, staffing, business case |

## Ownership and status
Assign an owner and status for each approved milestone during planning. Do not invent dates, budgets, metrics, or partners. Record significant scope decisions in [Decisions](DECISIONS.md).
